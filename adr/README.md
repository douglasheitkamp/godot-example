# Architectural Design Decisions

This directory contains ADRs (Architectural Design Decisions) for the Godot Example project.

## Structure

- `001-use-godot.md` - Decision to use Godot Engine
- `002-humble-bundle.md` - Decision on Humble Bundle purchase

## Template

Each ADR follows the [ADR format](https://adr.github.io/madr/):

```markdown
# ADR XXX: Title

## Context

## Decision

## Status

## Consequences

## Links
```
